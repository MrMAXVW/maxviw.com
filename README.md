## 💎 Design Philosophy
The site is built on the principle of **Invisible Sophistication**. It features a "dark-mode first" aesthetic to cater to modern professional tastes, emphasizing readability and high-end animations.

### Key Features:
* **Dynamic Glass Reflection**: Interactive "light-sweep" effects on expertise cards for a premium feel.
* **Active Timeline Connector**: A synchronized GSAP scroll-trigger that visually connects my career path as you read.
* **Split-Text Animations**: High-performance typography reveals powered by GreenSock.
* **Fully Responsive**: Optimized layouts for mobile, tablet, and desktop viewports.
* **Technical SEO**: Lightweight structure with rapid load times.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, TailwindCSS (Utility-first styling)
* **Animation:** [GSAP](https://greensock.com/gsap/) (ScrollTrigger, ScrollToPlugin)
* **Typography:** Montserrat & Space Grotesk via Google Fonts
* **Icons:** Lucide Icons
* **Deployment:** GitHub Pages
